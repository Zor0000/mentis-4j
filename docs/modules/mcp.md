# MCP server implementation

Mentis exposes the same registered tools over two transports: a local stdio server and an optional Cloudflare Worker using Streamable HTTP. Tool registration is in `src/lib/tools.ts`.

## Stdio server

`src/process/server.ts` is the Node.js entry point. It loads `.env` from the process working directory when the file exists, creates a Neo4j `Database`, and verifies connectivity before it registers or serves tools. It then connects `McpServer` to `StdioServerTransport`.

The server uses the name and version in `CONFIG.app`. Startup diagnostics and request logs are written to stderr; stdout is reserved for MCP protocol messages. `SIGINT` and `SIGTERM` close the MCP server and database. Startup failures set the process exit code to 1 and close an opened database.

The built entry point is `dist/process/server.js`. Build output is generated by `npm run build`; do not edit `dist/` directly. The `.env` path is relative to the working directory, not to the entry-point file.

## Worker transport

`src/server/worker.ts` exports the Worker fetch handler. It serves only `/mcp`; other paths return 404. The endpoint accepts POST requests and returns 405 with `Allow: POST` for other methods.

For each request, the Worker validates its environment, creates a Neo4j database connection and a new MCP server, registers the same tools, and connects a `WebStandardStreamableHTTPServerTransport`. The transport has no session ID generator and enables JSON responses. The handler closes the MCP server and database in `finally` after handling the request.

The Worker requires `NEO4J_URI` and `NEO4J_PASSWORD` to be set. It does not call `verifyConnectivity()` during setup. Neo4j errors or request handling errors are logged and returned as a generic 503 response. Invalid configuration also returns 503. The Worker environment accepts optional `NEO4J_USERNAME`, `NEO4J_DATABASE`, `OPENROUTER_API_KEY`, and `LOG_LEVEL`; Neo4j username and database default to `neo4j`. The OpenRouter key is checked when a tool makes an embedding or relevance request, not during environment parsing.

The Worker endpoint has no authentication. Anyone who can reach it can invoke tools, read or modify graph data, cause embedding-provider requests, and submit agent-authored Cypher to `recall`. Do not expose it to untrusted callers or sensitive data.

## Logging

`src/lib/logger.ts` writes one JSON object per line to stderr. Levels are `debug`, `info`, and `error`; the default is `debug`. `LOG_LEVEL` sets the minimum level. Invalid values fall back to `debug` in the logger. When supplied, a request ID is emitted as `request_id`.

## Security boundary

`recall` executes caller-authored Cypher in a Neo4j read transaction with result and time limits. These limits constrain resource use and output size. They do not make the tool a complete read-only security boundary. Use a restricted Neo4j credential and verify its permissions before deployment beyond trusted local use. The Worker has no caller authentication, and the default Neo4j user is `neo4j`.
